# 图片去重与图文组合（开发分支，未发布）

一条图文组合可以保存配文和 1–50 张图片，合计 PNG 不超过 100 MiB；单图仍受 20 MiB、1600 万像素 / 64 MiB RGBA 限制。列表以九宫格显示前九张与剩余数量；详情逐张读取原图，可修改配文、标题、分组与保留方式。图片分类按记录计数，一条图集计一条。图片与配文均在本机保存，图集不向 AI 提供，配文和标题仍执行本地隐私扫描。

当前数据模型是「一段配文 + 有序图集」：保存图片之间的顺序和重复位置，**不保存文字段落与图片交错的原始排版**。整组复制的 HTML 先放配文，再按图集顺序放图片；不能将「文字 → 图 → 文字 → 图」的任意交错顺序记为已支持。入口：`store/bundles.rs`、`desktop/media.rs`。

## 图片查看器（2026-11-05）

单图和图集详情均提供「全屏查看图片」，铺满当前软件窗口。图集从当前选中的图片进入，支持上一张 / 下一张与左右方向键，首尾不会循环。只读取当前一张原图，不一次加载全部原图。

支持适应窗口、原始大小、1–400% 缩放、滚动和平移；`+` / `−` 调整缩放，`0` 适应、`1` 原始大小，Ctrl/⌘ + 滚轮缩放。Esc 先关闭查看器并保留底层详情与编辑草稿，不触发历史快捷复制。详情未展开的隐私图片不可进入，切换记录、保护状态或详情复核失败会关闭查看器。源码入口为 `ImageViewer.vue`、`ClipGallery.vue` 和 `App.vue`；浏览器与 macOS 原生代表场景见 [验证记录](verification.md#图片查看分页与收藏排序2026-11-05开发分支未发布)。

## 采集与复制

- 一次复制的本地 PNG / JPEG 文件列表中含两张以上图片时，收成一条图集；同时提供的真实文字保留为配文，文件名 / 路径列表不当作配文。一个图片文件带文字，或系统位图同时带文字，也可收成一条图文。单个普通图片文件仍是文件引用；混有非图片、缺失文件或链接时不读取文件内容，保留文件引用。
- 不从 HTML 抓取远程图片，不将同一内容的不同编码计成多张图；目前未实现所有来源应用私有格式、多个原生位图项目或远程 HTML 图集的采集。静态 PNG / JPEG 以完整 RGBA 转成 PNG，JPEG 应用方向信息后转换，不保留压缩源文件与 EXIF。
- 整组复制同时写入完整图片文件列表、纯文本、星笺组合标记；完整内嵌 PNG 的 HTML 不超过 8 MiB 时再提供 HTML，超过则整份省略，不写残缺图集。目标应用可能只接收其中一种格式，不能保证一次粘贴同时出现全部图文。详情另有「复制为纯文本」与「只复制图片」。没有文字的图集仍提供图片文件列表。
- 复制 / 拖出使用明文临时 PNG，24 小时后在后续传出时清理，约 512 MiB 缓存上限；长期保留使用目录导出。写入后复核必需的系统格式，再报告复制成功；图文组合的自身采集标记还要校验文字与每张图片，不能只信令牌或哈希。
- 多选已有图片或图集后，「收藏为一条图文」可添加配文并星标收藏；按选择顺序展开各图集，保留原记录和已有配文，任一原记录受保护则组合也保留隐私保护。

## 严格去重

单图先用尺寸与完整 RGBA 的 SHA-256 查候选，再比较完整 PNG 字节；字节不同则有界解码并逐字节比较 RGBA，包括透明像素的 RGB 与 Alpha。标准字节比较发现差异即结束，不随机取样，不以感知相似度合并。摘要索引不再唯一，模拟碰撞时可以保存两张不同图片，不会触发旧 upsert 覆盖。

组合身份由精确配文与有序图片内容共同决定，顺序不同或配文不同是不同记录；同一图集中的重复图片保留重复位置。图集之间共享经完整验证的图片资源，最后一条引用删除后才删除资源；旧单图仍沿用原表，不宣称单图与图集完全共用同一 BLOB。重复采集复用记录、更新最近时间，保留星标、永久保留、分组与隐私依据。主动编辑成已有的完全相同组合会提示编辑原记录。

## 分享素材收藏

「偏好设置 → 分享」的「收藏本语言全部图片」把当前素材语言的五张产品图存成一条星标图集；「收藏这段文案」单独收藏当前文案。两种语言与两类文案按内容独立去重，不自动灌入新库，不授经验、不自动发布、不上传剪贴内容。素材本身仍是固定原创样例，参见 [分享说明](product-share.md)。

## 数据兼容

本开发分支使用 SQLite 结构 **5**、历史 JSON **5**，支持导入 JSON 1–5。结构 4 升级前先保存一致快照，再事务新增组合与图片资源表、调整去重索引，保留旧记录身份与保护；已识别的旧结构 2 / 3 也沿既有快照路径升级。旧程序应拒绝打开结构 5，程序回退要配套升级前的数据副本。JSON 5 同时保存原图、配文、顺序和重复项；缺图、数量 / 尺寸不符或损坏时整次导入失败。JSON 仍受既有 20 MiB 等总额限制，大图集可使用完整恢复点，不会裁图后报告备份成功。浏览器演示继续拒绝图片 / 图文备份，避免丢图。

本地存储版本独立于埋点协议；本次不改变遥测 v4，也不需要切换 Cloudflare Worker。当前自动检查和原生实测边界见 [验证记录](verification.md)。
